# 1win Aviator Next Value Analyzer

A modern Android application built with Kotlin, Jetpack Compose, Material 3, and Room Database designed to analyze completed 1win Aviator round data from authorized public/partner data interfaces and generate transparent statistical next-value estimates.

---

## 1. Overview & Data Flow Architecture

The application strictly implements the following non-invasive, one-way statistical pipeline:

```
1win Aviator (Public/Authorized API)
            ↓
Authorized Data Connection (HTTPS Validation)
            ↓
Completed Round Data (Room Database Persistence)
            ↓
Analysis Engine (Transparent Statistical Synthesis)
            ↓
NEXT ESTIMATED VALUE (Single Dynamic Multiplier, e.g. 1.87x)
```

The application **never** claims that an estimate is guaranteed to be the actual future result.

---

## 2. Key Features

- **ONE Primary Dynamic Estimate:** Synthesized dynamically from historical completed rounds (no hard-coded values, no arbitrary clutter of 10–15 numbers).
- **Authorized Connection Layer:**
  - Dedicated `OneWinAviatorDataSource`, `OneWinRepository`, and `OneWinApi` layers.
  - Strict HTTPS communication with optional authorized API Key headers.
  - Clear Connection Status (`● CONNECTED` / `● DISCONNECTED`), with `CONNECT`, `TEST CONNECTION`, and `REFRESH` controls.
- **Automatic Round Processing:**
  - Validates newly completed round records.
  - Rejects incomplete/in-progress rounds, negative or zero multipliers, and duplicate round IDs.
  - Emits real-time notifications with previous vs. updated estimates.
- **Configurable Polling Intervals:** 5s, 10s, 30s, 60s, or Manual refresh.
- **Historical Round Log (Room Database):**
  - Searchable, filterable list of all completed rounds with formatted timestamps and color-coded multiplier tags.
- **Interactive Statistical Analytics Screen:**
  - Dynamic descriptive statistics: Rounds Analyzed, Arithmetic Mean, Median, Min, Max, Standard Deviation, and Exponentially Weighted Moving Average (EWMA).
  - Custom Canvas **COMPLETED ROUND HISTORY** graph with horizontal threshold guidelines and gradient curves.
  - Frequency distribution breakdown (< 2.0x, 2.0x–5.0x, 5.0x–10.0x, 10.0x+).
- **Data Management & Portability:**
  - CSV Import & Export for offline auditing and backup.
  - Clear database and sample data seeding tools.
- **Demo Mode:**
  - Allows full offline exploration without a live connection.
  - Prominently displays `DEMO MODE — NOT LIVE 1WIN DATA`.
  - Uses mathematically authentic provably fair crash distribution characteristics.

## 3. How the Analysis Engine Works (`PredictionEngine.kt`)

The engine takes `List<Round>` containing only verified **completed** rounds and applies transparent, documented mathematical models:

1. **Robust Median:** Because crash games feature extreme high multipliers (e.g., 50x, 100x), a simple arithmetic mean is severely distorted by single spikes. The median represents the true middle outcome unaffected by rare outliers.
2. **Winsorized / Trimmed Mean:** Clamps the upper 5th percentile extreme tails to establish a normalized historical average.
3. **Exponentially Weighted Moving Average (EWMA):** Evaluates the most recent 15 rounds with decay weighting ($\alpha = 0.25$) to track short-term clustering and local variance.
4. **Dynamic Synthesis Formula:**
   $$\text{Next Estimated Multiplier} = 0.40 \times \text{Median} + 0.35 \times \text{EWMA}_{\text{recent}} + 0.25 \times \text{Mean}_{\text{trimmed}}$$
5. Clamped between $1.01\text{x}$ and realistic bounds, rounded to two decimal places.

### Why an Exact Multiplier Cannot Legitimately Be Guaranteed

Aviator utilizes a **provably fair cryptographic algorithm** based on SHA-512 hashes combining a server seed with three client seeds before each round begins. Because the random outcome is generated by a cryptographically secure pseudo-random function whose output is uniform across independent trials, each round is statistically independent. 

Any app or service claiming to "guarantee", "hack", or "predict exact outcomes" of future Aviator rounds is scientifically fraudulent. This application is an analytical tool for studying empirical completed-round tendencies, not a crystal ball.

## 4. Security & Compliance Mandates

This application strictly complies with security, ethics, and Google Play policies:

- **No Passwords or OTPs:** Never prompts for, stores, or transmits 1win credentials, one-time passwords, or phone numbers.
- **No Session Cookies or Token Theft:** Operates strictly on public or authorized data endpoints.
- **No Game Manipulation:** Does not alter game states, intercept encrypted TLS traffic, or inject code.
- **No Private or Unreleased Data Access:** Never attempts to access future round multipliers before the round has naturally finished.
- **Local Privacy:** All round records and calculations are processed locally on the user's device in an encrypted Room SQLite database.

## 6. How to Open and Build the Project

### Prerequisites
- Android Studio Ladybug or newer
- JDK 17 or JDK 21
- Android SDK 36 (target and compile SDK)

### Opening in Android Studio
1. Clone or download the repository.
2. Open Android Studio and select **File > Open**, navigating to the project directory.
3. Allow Gradle to sync dependencies automatically via the Version Catalog (`gradle/libs.versions.toml`).

### Building the APK
Run the following Gradle command in terminal:
```bash
gradle assembleDebug
```
The output APK will be generated at:
`app/build/outputs/apk/debug/app-debug.apk`

### Running Unit and Robolectric Tests
```bash
gradle :app:testDebugUnitTest
```

## 7. Configuring the Authorized 1win Data Source

1. Navigate to the **Settings** tab in the bottom navigation bar.
2. Select **Authorized 1win API** under Data Source.
3. Enter your authorized partner or endpoint URL in **API Base URL** (defaults to `https://api.1win-data.com/`).
4. (Optional) Provide your authorized API Key in the **API Key** field.
5. Tap **Save API Configuration**.
6. Switch back to the **Home** tab and tap **Test Connection** or **Connect**.
